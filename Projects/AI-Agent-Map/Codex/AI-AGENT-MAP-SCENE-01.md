# Scene 1 - The Lost Agent

Video title: The Graph Behind Smart AI Agents

Audience: AI learners

Target length: 10-12 seconds

Purpose: Open with the problem. An AI agent can appear capable, but without a workflow structure it may wander, repeat itself, skip checks, or choose the wrong next step.

## Concept Accuracy

This scene is about agent workflow control, not multi-agent systems.

Credibility-safe claim:

> An AI agent needs more than a prompt. It needs a structured way to decide what step comes next.

Avoid saying:

- All agents are multi-agent systems.
- Graph engineering is the only way to build agents.
- A graph makes agents automatically intelligent.
- Prompt engineering is useless.

## Voiceover Draft

Line 1:
"An AI agent can sound smart..."

Line 2:
"but without a map, it can still get lost."

Line 3:
"It may research twice, skip verification, or jump to the wrong next step."

## On-Screen Text

Minimal text only:

- Smart?
- Lost.
- No map.

## Visual Beats

Beat 1:
A single glowing dot appears in dark space. It represents the agent.

Beat 2:
The dot receives a large prompt block. The prompt block glows, then fades into many possible paths.

Beat 3:
The dot moves randomly between faint nodes. Some nodes flash briefly:

- Research
- Draft
- Check
- Publish

Beat 4:
The dot loops back to Research, skips Check, then rushes toward Publish. The path looks unstable.

Beat 5:
The camera pulls back. The viewer sees disconnected nodes floating without a clear route.

End frame:
Text appears: "No map."

## Motion Direction

Feel interactive, not slide-based:

- Camera should drift through the node space.
- Nodes should react when the agent passes near them.
- The agent dot should leave a fading trail.
- Wrong moves should feel visually obvious but not cartoonish.
- Keep the background clean and dimensional.

## Shape Language

- Agent: small bright circle.
- Prompt: large rectangle made of many tiny text-like lines.
- Tasks: circles or rounded squares.
- Failed path: thin unstable line.
- Future map hint: faint geometric grid in the background.

## Sound Direction

- Soft digital pulse when the agent appears.
- Slight glitch when it loops or skips the Check node.
- No loud robotic sounds.
